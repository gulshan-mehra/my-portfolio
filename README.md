## 🕹️ Featured Projects

### 🎨 1. ColorFolks *(Commercial Multiplayer Game)*
- **Client / Platform:** Commercial Title &middot; Mobile (Android / iOS)
- **Stack:** `Unity` &middot; `C#` &middot; `Photon Fusion` &middot; `Shader Graph` &middot; `Draw Call Optimization`
- **Overview:** Multiplayer hide-and-seek game inspired by *Mecha Chameleon*. Players paint characters with colors and broadcast paint patterns to all connected players in real time.
- **Key Technical Highlights:**
  - Designed host-authoritative networking architecture using **Photon Fusion**.
  - Built real-time character surface painting synchronized across network clients using compressed delta RPC payloads.
  - Optimized rendering down from 400+ to **< 120 draw calls** via GPU instancing and texture atlasing for locked 60 FPS on mid-range mobile devices.

### 🌿 3. Grass Shader Pack & Water Shader Pack *(Unity Asset Store)*
- **Platform:** Unity Asset Store (Published Packages)
- **Stack:** `Shader Graph` &middot; `Custom HLSL` &middot; `Unity Editor Tooling`
- **Overview:**
