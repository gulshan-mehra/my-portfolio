06 — ENGINEERING NOTES

Engineering Notes

Technical deep-dives from real project challenges.

For the Grass Shader Pack, pure Shader Graph wasn't sufficient for wind animation quality. I wrote custom HLSL subgraphs for per-vertex wind displacement with LOD-aware blending. The editor tool was built as a custom EditorWindow — users can switch between "paint" mode (raycast-based placement) and "combine" mode (static mesh merging for draw call reduction). The UI mirrors Unity's terrain tools to keep the workflow familiar.

The core challenge in ColorFolks was synchronising shader paint data across all clients with minimal bandwidth. Paint events are sent as compressed delta payloads over Photon RPCs, and the local Shader Graph reads from a Render Texture updated each frame. Host-authoritative validation prevents cheating, while client-side prediction keeps paint feel instant. On mobile, paint mesh updates are batched to avoid per-frame draw call spikes.

On ColorFolks' mobile build, initial profiling showed 400+ draw calls per frame. Using the Frame Debugger and Profiler GPU timeline, I identified heavy overdraw from the paint shader system and unsorted transparent geometry. Solutions: GPU instancing on character meshes, texture atlasing for UI, and sorting layer re-ordering. Final build hit under 120 draw calls — smooth 60fps on mid-range Android.

The RAG Document Q&A system runs entirely locally. Documents are chunked, embedded using a sentence transformer, and stored in Qdrant. On query, the top-k relevant chunks are injected as context into the Qwen 2.5 7B prompt via llama.cpp's REST interface. FastAPI handles auth and query routing. PostgreSQL manages users and metadata.

Migrating from Classic Input Manager to Unity's New Input System required rebuilding the entire UI navigation layer. I created a centralised InputManager singleton broadcasting input events, then built a custom SelectionNavigator for UI panels. Joystick/D-pad navigation uses Unity's EventSystem with custom navigation overrides per panel — seamless keyboard/mouse/controller switching at runtime.
